# About

Backend engineer with 5 years of experience building scalable backend systems, APIs, and business platforms. I specialize in designing reliable data flows, integrating complex third-party ecosystems, and architecting backend services that coordinate multiple systems through event-driven and queue-based workflows.

Recently I've been focused on AI-assisted development and agentic system design—using LLMs to accelerate development while building autonomous workflows that combine business logic, APIs, orchestration, and automation into maintainable production systems.

My experience includes:

- Backend architecture and scalable system design
- AI-assisted development and agentic workflow design
- Business workflow and data flow architecture
- REST API development and third-party integrations
- Event-driven and queue-based processing
- Multi-tenant SaaS platforms
- Automation pipelines using n8n
- Payment gateway and subscription systems
- CI/CD, deployment and infrastructure
